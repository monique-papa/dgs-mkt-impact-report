# 📄 GitHub Pages Setup

Ativa o GitHub Pages para publicar o relatório automaticamente.

---

## 🚀 Ativar GitHub Pages

1. **Settings** → (no repositório)
2. **Pages** (menu esquerda)
3. **Source:**
   - Branch: `main`
   - Folder: `/docs` (padrão)
4. Clica **Save**

---
